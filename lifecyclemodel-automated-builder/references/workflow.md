# Model authoring sequence

Establish scope and functional quantity; select exact Process references and units; author only explicit instance/port connections; inspect `dataset model graph`; validate; then separately create/save when authorized. Query and choose missing dependencies rather than inventing them. `run-lifecyclemodel-automated-builder.mjs` forwards current Model actions and their native arguments, with no run-directory authoring protocol.

Use the Study workflow for evidence intake and Model preparation/calculation. `build-resulting-process` creates candidate content, not a saved Process or a calculation Run. Retain task notes and unresolved decisions independently of CLI result files.
