# Model source and validation authority

Read the selected CLI's `dataset model contract` for current schema and public rules, and its graph/validate help for supported inputs and checks. Platform graph conventions can inform presentation but do not authorize new persistence fields or make a UI payload a canonical Model.

Validation and calculation belong to CLI/Worker capabilities. Skills select evidence, assemble explicit Process references/connections and report findings. Do not call a private Python validator or import a sibling repository; a missing supported check remains unverified.
