# Process authoring responsibilities

The Agent selects the scientific unit, sources, assumptions and reuse decisions. Current CLI provides typed contract/search/get/list-references/validate/diff/patch/create/save operations. Foundry owns registered production tasks and their actions; do not replace those actions with standalone wrapper calls.

There is no standalone CLI build-plan, automatic authoring, evidence-search or publication queue. Keep editable research notes and canonical candidate files. Evidence gaps are explicit; validate actual candidate content and preserve unknown write recovery before proceeding.
