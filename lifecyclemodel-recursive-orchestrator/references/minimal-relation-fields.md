# Relations and provenance

The installed CLI contract owns canonical Model references and returned Process relations. Record exact selected identities and the explicit source of a generated candidate. Do not invent generated_from fields, projection signatures, a relation table or a new persistence schema inside a Skill.

Use native Model/Process content and command results for supported relations. If an inverse lookup is unavailable, report it as unverified; outgoing list-references does not prove that no consumers exist. Graph layout, screenshots and caller notes do not replace scientific content.
