# Dependency-oriented authoring

The caller maintains the modeling worklist and decides scientific boundaries. Exact typed get/list-references/graph/validate operations expose dependencies; they do not create a recursive production queue. Track visited identities to distinguish repeated use from circular structure. Do not recursively expand aggregated background LCI.

Missing source evidence or an inaccessible exact reference stays unresolved. Author only supported candidates, validate each and perform separate explicitly authorized writes with independent receipts. Partial completion and unknown write outcomes must survive handoff. Registered Foundry tasks keep their own returned actions and runtime.
