# Model and Process identity

Model is the canonical composition of explicitly selected Process instances and connections. Each reused remote Process has an exact ID/version; local draft content can remain an editable file. A reference process defines the modeled demand. Background aggregate LCI is a selected boundary and is not recursively expanded.

Use `dataset model contract`, `graph` and `list-references` to inspect the supported representation. Keep native `referenceToResultingProcess` and service-returned relations when present; the Skill does not mint a second relation protocol or require projection hashes. Caller notes may record why each dependency and boundary was selected.

Create/save is an explicit persistence decision. Editing a local draft or rerunning a calculation does not automatically increment remote dataset versions. Layout and screenshots are presentation artifacts, not scientific identity.
