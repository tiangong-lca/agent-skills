# Evidence intake

Use this guidance when the user needs help identifying and supplying materials. It can be delegated independently of the rest of the Study; pass the goal and any provisional functional unit/boundary, then return a source inventory and the next material question.

Group materials by the operation they describe: product composition, production, purchased energy, transport, waste treatment, direct emissions and use/end of life when in scope. Ask for the denominator as well as the amount: per item, batch, hour or reporting period, including production output and losses for that same boundary. Request geography and time only where they affect representativeness.

Record the original filename and a stable local location, author or owner if supplied, relevant page/sheet/section, units, period, confidentiality and extraction status. Keep private originals in the authorized workspace; attaching them is not permission to upload or publish them. If a file cannot be read, describe what is unreadable and ask for the smallest useful alternative.

Return a concise material inventory with useful sources, unresolved scope questions and missing source types. Do not require a universal folder schema, digest or server registration before extraction can proceed. Avoid asking again for facts already present in readable sources.

Begin with a small request in the user's language: for example, one product specification, an available material/production sheet and an energy bill. Accept the files as maintained by the business; use an optional checklist to explain gaps after reading them. Do not require a fully populated standard workbook before making progress. When the user cannot yet specify scope, suggest a provisional interpretation and identify what evidence or decision will settle it.
