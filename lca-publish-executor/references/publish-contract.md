# Persistence, review and publication

A dataset draft write, review submission, reviewer decision and data-product Release are separate business effects. Use typed create/save for explicitly authorized draft persistence; review submit/resubmit for author submission; review get/list/materials for state; and current role-authorized review handling for decisions. Inspect the installed help for actual service semantics, including related-data submission limits.

The convenience script forwards review actions only. It never translates a generic publish request into a combined transaction or a Release operation. Preserve each actual receipt and unknown outcome. Data-product Release remains a separately requested workflow with its existing contract.
